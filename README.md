## ⚠️ ক্রম মানতে হবে

**আগে নিয়ম, পরে অ্যাপ।** উল্টো করলে নতুন অ্যাপ যন্ত্র দখল করতে
গিয়ে আটকে যাবে — পুরনো নিয়ম `controllerId` চেনে না।

**ধাপ ১ — নিয়ম (GitHub-এ নয়)**

`rules/firestore-poultry.rules.txt` খুলে পুরো লেখা কপি করুন →
Firebase Console → Build → Firestore Database → **Rules** ট্যাব →
পুরনো সব মুছে পেস্ট → **Publish**।

**ধাপ ২ — ওয়েবের ফাইল**

চারটা ফাইল GitHub-এ তুলুন: `poultry-app.html`,
`poultry-admin.html`, `switch-app.html`, `bd-locations.js`।

**ধাপ ৩ — যন্ত্র**

`firmware/README.md` দেখুন।

## ⚠️ যা কোনোদিন গিটে তুলবেন না

`hb_secrets.h` — এতে প্রতিটা যন্ত্রের নিজের গোপন শব্দ থাকে। একবার
উঠে গেলে ইতিহাস থেকে মোছা কঠিন, আর যে কেউ ওটা দিয়ে আপনার যন্ত্রের
নামে ক্লাউডে ঢুকতে পারবে।

`.gitignore`-এ আটকানো আছে, তবু তোলার আগে একবার দেখে নেবেন।

অ্যাডমিনের **দ্বিতীয় ছাপা তালিকা** (ইমেইল আর গোপন শব্দ) —
কর্মশালার বাইরে যাবে না, গ্রাহককে দেবেন না।

> HTML ফাইলে যে Firebase `apiKey` আছে সেটা **গোপন নয়** — ওটা
> সবার জন্যই খোলা থাকার কথা। নিরাপত্তা আসে Firestore-এর নিয়ম
> থেকে, চাবি লুকিয়ে নয়।

### ফোনে কোনো শব্দ হবে না

সতর্কবার্তা অ্যাপে দেখা যায়, কিন্তু **অ্যাপ বন্ধ থাকলে ফোনে কিছু
আসবে না**। সত্যিকারের push নোটিফিকেশনের জন্য Firebase-এর Blaze

ওটা নেট ছাড়াই বাজে।
